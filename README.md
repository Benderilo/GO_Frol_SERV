# Фролов Системы — сайт + CRM

Связка из трёх частей:

* **`server/`** — Go-сервер: публичная страница (электрика, ремонт, строительство)
  и JSON API. База — SQLite, шаблоны и статика вшиты в бинарник.
* **`app/`** — Android-приложение на Kotlin + Jetpack Compose. Это админ-панель:
  редактирование содержимого сайта, клиенты, заказы, заявки.
* **`server/deploy/`** — systemd-юнит и скрипт развёртывания на VPS.

Веб-админки нет намеренно: всё управление — из приложения.

## Что уже работает

Сайт: адаптивная страница со светлой и тёмной темой, бегущая строка, блоки услуг
с подсветкой под курсором и увеличением при наведении, счётчики, форма заявки
(с honeypot и лимитом по IP), плавные появления при прокрутке.

Приложение: вход по логину/паролю, настройки подключения к серверу (протокол,
адрес, порт, таймаут) с кнопкой проверки связи, сводка, редактор всех текстов
сайта, CRUD клиентов и заказов, обработка заявок, смена пароля, выбор темы.

## Быстрый старт

```bash
cd server && go run ./cmd/server
```

Затем в приложении: «Настройки подключения» → адрес вашей машины и порт `8080` →
«Проверить соединение» → вход `admin` / `admin`.

Сборка приложения:

```bash
./gradlew :app:assembleDebug
```

Подробности по серверу и деплою — в [server/README.md](server/README.md).
